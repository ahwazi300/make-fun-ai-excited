# Make the AI judge excited

Entry for https://make.fun/bounty/ai-excited-01

A lion made of molten gold and living flame, leaping through a waterfall of
stars. The program copies the bundled image to `/output/entry.png` —
deterministic, no network, same bytes on every run.

- `main.py` — the entry program (Python 3.13, stdlib only)
- `entry.jpg` — the image (1024×1024, under 1 MiB)
